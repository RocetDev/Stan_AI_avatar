# Stan AI
Веб-сайт написанный при помощи A-Frame и AR.js. Позволяет получить информацию о Стане для платической деформации металла и его состовляющих через ИИ ассистента.

## Конфигурация
Склонируйте репозиторий и рядом с index.html создайте фаил env.json который должен содержать в себе ключ и название моедли в OpenRotuer.

    {
	    "OPENROUTER_API_KEY": "<sk-ВАШ КЛЮЧ>",
	    "MODEL_NAME": "<название модели>"
    }
