# Stan AI
Веб-сайт, написанный при помощи A-Frame и AR.js. Позволяет получить информацию о Стане для пластической деформации металла и его составляющих через ИИ-ассистента.

## Конфигурация и запуск ИИ-ассистента
Основная версия приложения с интеграцией ИИ находится в файле `index.html`. 

Склонируйте репозиторий и рядом с `index.html` создайте файл `env.json`, который должен содержать в себе ключ и название модели в OpenRouter для работы ИИ-функций:

```json
{
    "OPENROUTER_API_KEY": "<sk-ВАШ КЛЮЧ>",
    "MODEL_NAME": "<название модели>"
}
```

## 🛠️ Сборка и экспорт AR-сцены

В проекте настроена автоматическая сборка, которая позволяет отвязать AR-компоненты от внешних CDN (все JS-библиотеки вшиваются локально) и упаковать саму сцену в различные форматы для демонстрации и интеграции.

*Примечание: Экспортируемые ниже форматы предназначены для демонстрации визуальной AR-сцены и интерфейса.*

### 1. Автономное приложение (Standalone)
Файл **`ar_app_standalone.html`** содержит в себе весь код сцены и тело библиотек. 
* **Как использовать:** Можно запускать локально или загружать на хостинг как самостоятельную страницу. Работает автономно и без интернета.

### 2. Вставка на сторонние сайты (Iframe-сниппет)
Если вам нужно встроить AR-сцену внутрь существующего сайта или веб-интерфейса, используйте файлы сборщика iframe:

* **`ar_iframe_snippet.txt`** — содержит чистый изолированный тег `<iframe>` с закодированным внутри AR-приложением. Разработчику достаточно скопировать этот кусок кода и вставить в любое место HTML-страницы своего сайта.
* **`ar_preview_page.html`** — готовая страница предпросмотра, демонстрирующая, как этот iframe будет выглядеть и работать на веб-странице (с правильной кодировкой, исключающей появление «кракозябр»).

### 3. Формат электронного курса (SCORM 1.2)
Для интеграции интерактивной AR-сцены в образовательную среду (СДО / LMS), запустите скрипт генерации пакета. Скрипт создаст архив **`ar_course_scorm12.zip`**.

* **Поддерживаемые СДО:** Moodle, iSpring Learn, WebTutor и любые другие системы с поддержкой стандарта SCORM 1.2.
* **Автотрекинг:** Внутрь пакета встроен JavaScript-коннектор к API СДО. Как только пользователь открывает курс и запускает AR-сцену, в систему обучения автоматически отправляется статус **«Прогресс: Завершено» (`completed`)**.
